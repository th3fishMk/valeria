# valeria

Opinionated extension that helps me and my team save a few clicks.

## Features

- [x] Create template files from templates
- [ ] Buy you more AI tokens

### Automatic file creation

How does this extension work:

There are two main ways:

- To use our templates, right click a folder and select "Valeria \<language\>", for example "Valeria C#" and select a template.
- To use your custom templates, select "Create file", give it name and an extension, and then select one of your previously created snippets to fil the file. The snippet shown depend on the file extension.

If you don't know how to create a snippet, plz visit the [official ms documentation](https://code.visualstudio.com/docs/editing/userdefinedsnippets#_create-your-own-snippets).
